# День 4. Агенты, LangGraph и MCP

> Книга 4 из 7 серии «ИИ-инженер: практический трек за неделю». Один день, 4–6 часов.

---

## Цель дня

К вечеру ты:

- объясняешь, что агент — это цикл «модель просит инструмент → код выполняет → модель смотрит на результат», и где в этом цикле живут безопасность, лимиты и деньги;
- отличаешь детерминированный workflow от агента и выбираешь простейшую схему, которая решает задачу;
- собираешь агента на LangGraph руками: состояние, узлы, условные рёбра, checkpointer, остановка по лимиту шагов и бюджету, обнаружение зацикливания, подтверждение человеком перед побочным действием;
- оборачиваешь свой сервис памяти в MCP-сервер и подключаешь его к агенту и к Claude Code — и можешь объяснить, зачем MCP, а не просто функция;
- имеешь право писать в резюме LangGraph и MCP — потому что теперь есть код.
