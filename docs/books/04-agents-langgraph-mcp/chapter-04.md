# День 4. Что показать работодателю

## Артефакт дня

`~/proj/ai-labs/day4-agent/` — агент на LangGraph, который можно прочитать за десять минут и увидеть в нём всё, о чём спрашивают: явное состояние, условные рёбра, три типа остановок, подтверждение записи через `interrupt`, checkpointer, учёт стоимости. Плюс MCP-сервер поверх собственного сервиса памяти и его подключение двумя клиентами. `results.md` с восемью прогонами показывает, что защита не декларация, а воспроизведённое поведение.

С сегодняшнего дня слова LangGraph и MCP в резюме честны.

## Формулировки для резюме

- Разработал агента на **LangGraph** с явным состоянием и условными переходами: инструменты поиска по документам и по долговременной памяти, инструмент записи под подтверждением человека (**human-in-the-loop через interrupt**), checkpointer для продолжения диалога.
- Реализовал **защиту агента**: лимит шагов, бюджет по токенам и стоимости из `usage_metadata`, обнаружение зацикливания по повторному вызову инструмента; все три остановки воспроизведены и задокументированы.
- Написал **MCP-сервер** (FastMCP, stdio) поверх собственного сервиса долговременной памяти агентов и подключил его к LangGraph через `langchain-mcp-adapters` и к Claude Code.
- Спроектировал и эксплуатирую **сервис долговременной памяти для ИИ-агентов** (FastAPI, ChromaDB, sentence-transformers, PostgreSQL): семантический поиск по проектам, типы «знание» и «решение», общий слой памяти для Claude Code, Codex CLI и Qwen Code.
- Эксплуатирую агента в Telegram (Hermes) в проде: systemd, политика сессий, смена моделей, обход геоблокировки провайдера — **agent operations**.

Ключевые слова: LangGraph, LangChain, agents, tool calling, function calling, MCP, Model Context Protocol, human-in-the-loop, checkpointer, guardrails, long-term memory, FastMCP.

## Как рассказать за 2 минуты

На вопрос «есть ли опыт с агентами»:

«Три уровня. В проде эксплуатирую агента в Telegram: systemd, смена моделей по цене, прокси при геоблоке, политика сброса сессий — то, что обычно называют agent operations. Построил сервис долговременной памяти для агентов — FastAPI и ChromaDB с локальными эмбеддингами — им пользуются мои coding-агенты через общие инструкции; это long-term memory как отдельный слой. И собрал агента на LangGraph руками: состояние, условные рёбра, три остановки — шаги, бюджет, повтор вызова, — запись только через interrupt с подтверждением, checkpointer для продолжения. Тот же сервис памяти обернул в MCP-сервер и подключил к агенту и к Claude Code. Мой принцип: workflow там, где порядок шагов известен — как в моём RAG-продукте, — агент там, где нет; и защита живёт в моём коде, а не в модели».
