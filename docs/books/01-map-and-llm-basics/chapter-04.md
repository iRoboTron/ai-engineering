## Формулировки для резюме

Правило одно: **сделал X с помощью Y, результат Z**, где Z — число или проверяемый факт. Готовые буллеты по твоим проектам; правь под себя, но не размывай:

- Спроектировал и вывел в прод **multi-tenant RAG-платформу** для ответов по документам компаний: FastAPI, ChromaDB с изоляцией коллекций по tenant, PostgreSQL с миграциями Alembic, эмбеддинги и LLM через OpenRouter; каналы — веб-виджет и Telegram-боты; админка с ролями platform-admin / admin / editor.
- Реализовал **честный fallback**: при отсутствии ответа в базе агент признаёт это и собирает контакт клиента вместо галлюцинации; добавил недельные отчёты по диалогам и учёт стоимости запросов к OpenRouter.
- Настроил **CI/CD с гейтом качества**: деплой по тегу через Ansible rolling update, self-test с проверкой RAG-ответов до переключения трафика, self-hosted GitHub Actions runner.
- Построил **сервис долговременной памяти для ИИ-агентов**: FastAPI, ChromaDB, локальные эмбеддинги sentence-transformers, PostgreSQL; семантический поиск по знаниям проектов; интегрирован с Claude Code, Codex CLI и Qwen Code.
- Эксплуатирую **LLM-агента в Telegram** в проде: systemd, OpenRouter, смена моделей по цене и качеству, обход геоблокировки провайдера через socks5-прокси, dashboard с аутентификацией.
- Развернул **self-hosted инференс**: Ollama и Open-WebUI за nginx с авторизацией и HTTPS; сравнение локальных моделей с облачными API по стоимости и качеству.
- **DevOps-фундамент**: Proxmox и LXC, Docker и Compose, nginx, PostgreSQL, Prometheus и Grafana, Ansible, GitHub Actions, Linux hardening — 38 написанных практических книг по DevOps как подтверждение системного понимания.
- Сегодняшнее: измерил стоимость и латентность LLM-запросов через OpenRouter для двух моделей, реализовал structured outputs с валидацией Pydantic и запасным путём, ретраи с экспоненциальным backoff — `github.com/iRoboTron/ai-labs`.

Ключевые слова, которые должны быть в резюме текстом, потому что по ним ищут рекрутеры: Python, FastAPI, LLM, RAG, эмбеддинги, векторная база (ChromaDB, pgvector), OpenAI API / OpenRouter, structured outputs, function calling, prompt engineering, Pydantic, PostgreSQL, Docker, CI/CD, Linux. Слова LangChain и LangGraph добавишь после дня 4, когда сделаешь агента на них — не раньше, честность проверяется на собеседовании за две минуты.

## Как рассказать за 2 минуты

Устный питч на вопрос «расскажите о себе» — выучи структуру, не текст:

«Я инженер с DevOps-фундаментом, последние полтора года строю продукты на LLM. Основной проект — multi-tenant RAG-платформа для ответов по документам компаний: FastAPI, ChromaDB, PostgreSQL, модели через OpenRouter, каналы — виджет на сайте и Telegram. Она в проде у реальных клиентов; из интересного — честный fallback вместо галлюцинаций, который собирает контакты, и CI с self-test-гейтом, который не пускает деплой, если RAG-ответы сломались. Второй проект — сервис долговременной памяти для ИИ-агентов с локальными эмбеддингами, им пользуются мои coding-агенты. Плюс эксплуатация LLM-агента в Telegram и self-hosted инференс на Ollama. Чего мне не хватало — системного измерения качества: метрики поиска, evals, трейсинг. Сейчас закрываю это на своих же проектах и ищу команду, где RAG и агенты — в проде, а не в презентации».

Последнее предложение — честное и выгодное: оно превращает пробел в план и показывает, что ты знаешь, чего не знаешь.
