## Формулировки для резюме — итоговый набор навыков

Группы навыков, каждая — только то, что подтверждено файлами этой недели:

- **LLM и RAG**: OpenAI-совместимые API (OpenRouter, YandexGPT), structured outputs, function calling, prompt caching, эмбеддинги для русского (text-embedding-3, bge-m3), chunking, гибридный поиск (BM25 + вектор, RRF), реранкинг (cross-encoder), метрики поиска (recall@k, MRR), RAGAS, LLM-as-judge.
- **Агенты**: LangGraph (StateGraph, checkpointer, interrupt/HITL, лимиты), tool calling, MCP (FastMCP-сервер, langchain-mcp-adapters), долговременная память агентов.
- **Данные и инфраструктура**: PostgreSQL + pgvector (HNSW, гибрид в SQL, RLS), ChromaDB, Docker Compose, Ansible, GitHub Actions, nginx, Proxmox/LXC, Prometheus/Grafana, Langfuse self-hosted, Ollama, vLLM (концепт и запуск).
- **Безопасность и РФ-контекст**: OWASP Top 10 for LLM 2025, red teaming, prompt injection defenses, маскирование ПДн, 152-ФЗ в схеме потоков данных, эксплуатация зарубежных API при геоблоке.
- **Инженерная культура**: evals в CI, golden-наборы, трейсинг, документация (авторские книги), работа с заказчиком.

«Я AI/LLM-инженер с DevOps-базой. В проде — multi-tenant RAG-платформа с клиентами, сервис долговременной памяти для агентов и агент в Telegram. За последнюю неделю сделал то, чего не хватало: измерил качество поиска и генерации на golden-наборе — recall@5 … → … после гибрида с реранкером, faithfulness … по RAGAS с откалиброванным судьёй; поднял pgvector с RLS рядом с Chroma и составил план миграции; собрал агента на LangGraph с лимитами и подтверждением записи и MCP-сервер к своей памяти; развернул Langfuse и сделал гейт качества для CI; провёл red team своего бота по OWASP — … из десяти атак до фиксов, … после. Всё воспроизводимо, в открытом репозитории. Ищу команду, где RAG и агенты работают в проде и где качество измеряют».
