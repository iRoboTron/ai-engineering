# День 7. Портфолио, проверка навыков и следующий шаг

> Персональный sprint, не экзамен на профессию. **4–6 часов — плановая гипотеза, не измеренный срок.** Результат недели может быть частичным; это нужно показать, а не скрыть.

## Цель дня

Собрать правдивый индекс доказательств: что объясняешь, что воспроизвёл в лабе, что действительно эксплуатировал. Найти пробелы по критериям ответа и одной самостоятельной задаче. Решение об откликах, уровне и публикации принимает читатель по подходящим вакансиям, не по обещанию курса.

## Тайминг minimum

| Блок | План |
|---|---|
| Глава 1 и проверка исходных материалов | 45–60 мин |
| Семь шагов лабы, включая mock на 12 вопросов | 190 мин |
| Три поведенческих ответа, один drill, финальная сверка | 45–60 мин |
| Резерв на сбои/переоценку | 20–40 мин |

Итого 5–5 ч 50 мин по плану. Запиши фактическое время; если материалы ещё не готовы, выбери один готовый артефакт, а не выдумывай результаты всей недели. Пропущенный MCP/vLLM/holdout не нужно срочно закрывать сегодня ради полного списка.

## Minimum и Definition of Done

- [ ] Индекс перечисляет выполненные и невыполненные лабы со статусами «концепт / лаба / прод».
- [ ] Один кейс содержит постановку, личную роль, проверенный результат, trade-off и ограничение; публикация допустима владельцем данных.
- [ ] Черновик резюме не содержит навыков и биофактов без подтверждений; публикация не обязательна.
- [ ] Есть одна реальная STAR-история либо честно обозначенный разбор учебного сбоя.
- [ ] Один system-design outline проверен на требованиях и двух изменениях ограничений.
- [ ] Mock на 12 вопросов оценён по трём тезисам каждого, сохранены оценки по дням и оговорка о малой выборке.
- [ ] Один самостоятельный debug-drill решён до чтения решения; слабые темы и фактическое время сохранены.

## Stretch — вне бюджета дня

Большой mock на 60 вопросов: 2–3 часа только на ответы/сверку, плюс разбор. Независимое интервью с инженером, ещё два drill, три STAR, второй кейс, публикация резюме, отклики и статьи — отдельные задачи по желанию. Повторная выборка из знакомого банка не доказывает перенос навыка на новую задачу.
