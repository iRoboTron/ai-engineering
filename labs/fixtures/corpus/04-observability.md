# Эксплуатация учебной базы Юг
В этой открытой инструкции нет реальных ключей, адресов инфраструктуры или переписки.

## Измерение
Загрузка модели и прогрев измеряются отдельно от времени поиска. Для сравнения хранилищ используются одинаковые вопросы, эмбеддинги и tenant-фильтры.
Медиана показывает типичную задержку, а p95 описывает медленный хвост. Одного запроса недостаточно для вывода о производительности.

## Публикация
Приватный корпус, индекс и трейсы остаются в каталоге .local, исключённом из Git. Публично размещаются только синтетические fixtures, исходный код и проверенные обезличенные результаты.
Ключи API хранятся в переменных окружения и никогда не записываются в Markdown-отчёт. Перед коммитом просматривают git diff --cached.
