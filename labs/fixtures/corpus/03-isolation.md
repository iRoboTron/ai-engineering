# Доступ к учебной базе Юг
Это вымышленный tenant, не связанный с реальной организацией.

## Роли и политика
Роль приложения rag_app имеет атрибуты NOSUPERUSER и NOBYPASSRLS. Администратор загружает данные отдельно, а обычные запросы выполняются прикладной ролью.
Политика row-level security фильтрует строки по tenant_id. Значение tenant берётся из проверенного сервером контекста пользователя, а не из аргументов языковой модели.

## Соединения
Контекст tenant устанавливается через set_config внутри транзакции и автоматически сбрасывается по её окончании. В пуле соединений нельзя полагаться на SET предыдущего запроса.
Отсутствующее или сброшенное значение tenant превращается в NULL через NULLIF. Тогда прикладная роль не видит ни одной строки.
