# Поиск в учебной базе Север
Это синтетическая документация вымышленного сервиса, а не данные клиента.

## Идентификаторы и запросы
Артикул фильтра для вентиляционной установки — ВЕНТ-204. Его ищут точным совпадением через BM25: семантически похожий артикул не заменяет нужную деталь.
Уточняющий вопрос «а сколько он стоит?» сначала превращается в самостоятельный вопрос с учётом предыдущей реплики. Этот шаг называется condense question.

## Ранжирование
Гибридный поиск объединяет плотный поиск и BM25 через Reciprocal Rank Fusion. RRF складывает обратные ранги, а не сырые скоры разных систем.
Реранкер получает двадцать кандидатов и оставляет пять. Если релевантного кандидата нет среди двадцати, перестановка не восстановит отсутствующий документ.
